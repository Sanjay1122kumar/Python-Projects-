# Python Projects

A collection of small Python projects covering data structures, algorithms, and everyday utilities. Each project is a single, self-contained script that you can run on its own.

## Projects

| Project | File | Description |
|---|---|---|
| Budget App | `Budget-App.py` | Track income and expenses, and see your remaining balance. |
| Hash Table | `Hash-Table.py` | A hash table data structure built from scratch (insert, search, delete). |
| Polygon Area Calculator | `Polygen-Area-Calculator.py` | Calculates the area of a polygon from its dimensions or coordinates. |
| Tower of Hanoi | `Tower-of-Hanoi-Algorithm.py` | Solves the classic Tower of Hanoi puzzle using recursion. |
| Configuration Manager | `configuration-manager.py` | Load, read, update, and save application settings. |

## Requirements

- Python 3.8 or newer

Check your version:

```bash
python --version
```

These scripts use only Python's standard library unless a script's imports say otherwise, so there is usually nothing extra to install.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Sanjay1122kumar/Python-Projects-.git
   cd Python-Projects-
   ```

2. Run any project:

   ```bash
   python Budget-App.py
   python Hash-Table.py
   python Polygen-Area-Calculator.py
   python Tower-of-Hanoi-Algorithm.py
   python configuration-manager.py
   ```

On Mac/Linux, use `python3` instead of `python` if needed.

## What You Will Learn From These Projects

- **Budget App**: classes, methods, and working with money values
- **Hash Table**: how dictionaries work internally, hashing, and collision handling
- **Polygon Area Calculator**: math and geometry in code
- **Tower of Hanoi**: recursion and problem-solving
- **Configuration Manager**: reading and writing settings, file handling
